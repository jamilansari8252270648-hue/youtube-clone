# 🎬 YouTube Clone

A modern and responsive **YouTube Clone** built using **React.js** and **Tailwind CSS**.  
This project replicates the core UI and functionality of YouTube, including video browsing, searching, and responsive layouts.

---

## 🔗 Live Demo

👉 https://dreamy-gumption-cad94c.netlify.app/

---

## 📌 Features

- 🎥 Browse YouTube videos
- 🔍 Search functionality
- 📱 Fully responsive design
- ⚡ Fast and smooth UI
- 🎨 Clean modern interface
- 🔄 State management using Redux
- 📡 Real-time data using YouTube Public API

---

## 🛠️ Technologies Used

- **JavaScript**
- **React.js**
- **Tailwind CSS**
- **Redux** (State Management)
- **YouTube Public API**
